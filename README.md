منصة اجتماعية عربية للتواصل والتعارف والمحادثة ومشاركة المحتوى.

---

## حالة المشروع

هذا المستودع مخصص للنسخة الأساسية من مشروع:

**افـنـدツينا🥀🖤**

المشروع مصمم ليعمل ببنية:

- واجهة HTML
- خادم Node.js
- Express
- PostgreSQL
- Socket.IO
- نظام مصادقة
- نظام ملفات ورفع وسائط
- حماية للطلبات
- قاعدة بيانات حقيقية

لا يتم تضمين مستخدمين أو رسائل أو منشورات أو أرصدة تجريبية داخل المشروع.
